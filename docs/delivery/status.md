## 开发协作规则

默认流程为 A 一次规划完整阶段与技术查证，B 连续实施/自检，A 集中审查、直接修局部问题并一次性交回较大返工。用户事项独立维护于 workspace，非阻塞项按当前可逆默认推进并顺延，答复、待复测/需重测与关闭按[沟通正本](../dev-rules/communication.md#item-lifecycle)维护。

2026-10-11 按用户要求重新逐文件同步并由同一 Agent 完成规划、实施与自审，范围见[流程同步计划](collaboration-process-plan.md)，逐文件结果、保留条件与真实检查见[同步记录](../evidence/collaboration-process.md)。单 Agent 任务连续完成各项职责后直接交付，独立 A 审查未发生，不再因默认流程额外要求用户转交。2026-10-13 按 A-019 将这些成果一并归入 M0；文档验证与产品验证仍分别判断，不能以文档检查替代产品门槛。

LOOP 只承接可延期且不违反当前必需门槛的 Agent 工作；新条目写明影响、替代办法、责任、触发与复测入口。需要用户的决定/权限/人工检查进入集中 Q/ACT/H，当前缺实现与自动检查仍由 Agent 完成。
