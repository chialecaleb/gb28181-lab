## 场景自审

| 场景 | 核对结论 |
| --- | --- |
| A 只给第一批或遗漏必需前置 | 回补同一完整计划，工作包不是许可节点 |
| 可逆偏好、已有同范围授权 | 记当前默认或复用授权继续，不冒充用户确认 |
| 单 Agent 全部完成 | 连续规划、实施、自检、自审修复和交付；独立审查 not-run，不额外交接 |
| 缺代码、自动检查失败 | Agent 修复，不转 H 项或降低门槛 |
| 必要真实参数缺失 | 先核对配置/授权，只登记不可替代缺项；独立验证继续 |
| 用户只授权部分 ACT 动作 | 只执行列明动作，未执行与未授权如实保留 |
| 人工通过后行为变化或失败修复 | 原结果保留，受影响步骤标需重测/待复测 |
| 多个审查问题 | 分角色集中返工；单 Agent 原任务继续，沿用 F 编号和证据 |
| 源码未变而依赖/样本/条件改变 | 核对旧证据适用性，受影响范围重新验证 |
| 本阶段返工、前置未合并 | 只 amend 本阶段，提供新基点；无 upstream 不证明未推送 |
| 文档完成但包含 M0 外测失败 | 分别报告，不建议直接合并整条依赖链 |
| 新阶段的旧材料、配置和测试 | 看用途/归属/合并证据再处理，保住资料与有效断言 |
| UI 图显示媒体、PTZ、安全和成功 | 只提取布局/视觉，按实际能力开放，示例不作协议证据 |
