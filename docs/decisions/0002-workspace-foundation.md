# ADR-0002 独立产品与协作工作区

- 日期：2026-10-07
- 状态：active
- 依据：用户要求建立三个远程仓库、Agent 开发基础、集中用户事项、分支保护与标准资料迁移。

## 决定

workspace、hub、lab 使用三个独立 Git 仓库，父仓库忽略产品目录，无 submodule、不固定组合版本，各自跟随 main 最新实现。标准原始文件集中到 workspace，产品保留独立需求、设计、协议解释、测试和发布能力。运行时标准浏览用本地导入或许可允许的打包，不依赖工作区在线可用。

用户事项集中到 workspace USER-ACTIONS，产品入口只导航。产品 AGENTS 自包含；从父目录工作时须显式读取目标仓库规则。工作区规则不假定自动跨独立 Git 根继承。

采用 Agent 连续开发、自测与集中审查；A/B 为职责，不自动启动多个 Agent。初始化完成后 main 通过 PR、必需 CI、线性历史保护；单维护者强制审批数为 0，无管理员永久绕过。许可证和 DCO 未确定，不从其他项目移植。

## 影响

本决定替代旧规则中“标准 PDF 必须位于产品 Git 仓库”和“产品维护独立用户事项台账”的组织要求，不改变产品完整标准能力、原文可追溯性或独立运行目标。已有需求编号、接口细节和历史验证记录保持可追溯。

文件位置可以迁移，事实不能重写：本轮检查是基础设施与文档自审，不代表重新审核全部标准、独立 Agent 审查或产品验收。验证见基础建设报告。
