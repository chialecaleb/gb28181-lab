# 交互与视觉规则

功能依据为[需求](../requirements.md)，技术结构为[设计](../design.md)。初版工作台的视觉参考见[下节](#initial-ui-reference)，功能阶段映射见 [M0 计划](../delivery/m0-plan.md)，原图只在本地索引。已有工作台实现和真实操作证据，当前范围见[状态](../delivery/status.md)；主观视觉验收仍未完成，不继承图片中的协议正确性或通过结论。

实验界面应呈现角色、拓扑、当前状态、执行动作、报文/媒体证据和失败原因；区分配置意图、实际观测与未验证。批量动作显示作用范围，长任务可取消并显示清理结果。

表单覆盖非法值、空值、批量冲突与回读；报文展示区分原始内容和解释，不隐式改写签名原文。高风险操作说明影响和恢复方式，普通查看不增加多余确认。协议细节只在帮助定位实验时展示，用户正常流程不暴露无关内部实现。

桌面与 Web 遵循同一业务语义；界面支持键盘、可读对比和错误反馈。实现时给出真实截图/交互证据；自动检查不代替主观体验批准。视觉选择可用可逆默认值推进，需要用户的实际取舍在 USER-ACTIONS 登记。

A 规划先说明用户目标、关键状态、视口与允许使用的参考；B 随完整功能切片实现正常/错误/恢复/窄窗路径，A 核对实际结果。无需等待全应用高保真图，也不把全部 UI 留到功能结束后。现有样式代码管理实际数值，文档不另抄一份色号/尺寸正本；新增组件与调整保留可访问性。

报告写明实际版本、平台、窗口/DPI/缩放、样本和检查步骤。覆盖可达的主动作、键盘/输入法、可见焦点、浮层退出/焦点恢复、长名称和错误文本；未运行明确标注。主观偏好在集中 H/Q 事项中给完整步骤/当前默认，不逐组件要求确认；代码错误和可自动验证的缺口由 B/A 修复。

## 初版工作台 UI 参考

2026-10-11 用户明确指定工作台图片作为初版实现参考，编号 `UI-WORKBENCH-001`，分辨率 1536×1024。原图经字节一致性核对后保存在 Git 忽略的本地参考目录，按[本地索引](../dev-rules/local-materials.md#local-reference)定位；此前的参考图保留。当前指定图作为后续初版视觉实现的首选依据，本轮只登记参考与设计约束，尚未据此调整应用界面。

文件 SHA-256：`71e258e21eea38c10f9dcf48b440259a1bb272d1a5e66276f238e7865b93b1a6`。图片文件不随仓库或应用分发，缺少本机副本时仍可依下表和需求继续开发。

| 图中区域 | 初版采用的布局和信息层级 |
| --- | --- |
| 顶部全局栏 | 品牌、实验空间选择、全局搜索、后台任务/通知/帮助、引擎连接状态和用户入口；清楚区分全局状态与当前设备状态 |
| 左侧导航 | 按概览、资源、实验、观测、管理分组；自操作工作台作为主操作入口，选中项使用蓝色强调 |
| 标题与实验上下文 | 页面标题配保存场景、操作历史、证据导出；下方横向上下文条展示模式、目标平台、设备/通道、信令/媒体传输、标准配置、测试模式与安全信息 |
| 目标设备树 | 位于内容区左侧；设备搜索、状态/角色筛选、添加入口、实验空间/平台目录切换、分组设备及通道层级；状态同时提供文字，不能只靠彩色圆点 |
| 中部操作与画面 | 页签组织操作、报文、时序和状态；媒体区域与旁侧媒体信息、数据源和设备状态摘要相邻，便于对照操作前后结果 |
| 右侧操作参数 | 按操作类别显示表单、能力支持与条款入口；PTZ/FI/预置位在对应能力实现后使用专门控件，底部集中准备报文、发送操作、停止等主动作 |
| 底部证据区 | 信令记录及类型/时间/关键字筛选；选择记录后并列查看原始报文、结构/字节解释和分层验证，保留关联证据入口 |
| 底部状态栏 | 引擎连接、活动任务、数据更新时间、字符编码和实际资源使用；只显示真实可观测数据 |

视觉基调为白色卡片、浅灰蓝背景、蓝色主动作与选中态、细边框、轻阴影和小圆角。参考图用于确定密度与主次，精确色值、宽度和间距由实际样式代码统一维护；中文标题、标签和正文保持可读，不照抄图中失真的文字。大屏保留“设备树—工作区—参数”三列和下方证据区，窄窗优先折叠辅助区域，主要操作、错误、停止与证据入口必须可达。

图片中的时间、账号、设备 ID、地址、条款号、报文内容、成功标记与媒体参数均为示意，不作为默认配置、协议向量或验收结论。接收媒体、素材预览、设备内部状态要按实际来源区分。当前四信令切片只开放已经实现的动作；媒体、云台、安全、完整用户权限及后续能力保留明确未实现/不可用状态，不能为了贴图显示虚假的画面、支持状态或成功结果。

后续 UI 实施时以本节与 [M0 用例](../delivery/m0-plan.md)联合核对：1536×1024 参考布局、1280×800 关键操作可达，以及缩放、键盘/输入法、空/忙/错误/取消和长内容状态。提交真实应用截图与交互结果，主观视觉检查仍在集中用户事项单独记录；本次图片登记只验证原图保存、指纹和文档一致性。
